All three third-party sources below use CC0 1.0 Universal. Original source URLs, exact download hashes and preparation steps are retained with the source package. Attribution is included even though CC0 does not require it.

  Source record: `plant-v17-work/source-polyhaven/SOURCE-LICENSE.json`.

The soil grain maps, furniture meshes, seams, pillow/throw simulation and existing room/PC artwork remain authored project assets. The five plants share one standard PBR foliage atlas/material; botanical variants remain distinct. No unlicensed furniture model was incorporated.

Current fabric maps are the six JPEG files in `soft-v17-work/textures/FINAL-MATERIAL-MANIFEST.json`. Albedo is sRGB; normal/ORM maps are non-color, OpenGL +Y tangent normals. ORM is R=occlusion, G=roughness, B=metalness. The botanical diffuse PNG contains the official separately supplied alpha, thresholded at 0.5. All sources are linked in the accompanying manifests.
